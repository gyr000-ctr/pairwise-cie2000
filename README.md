# pairwise-cie2000

## 题面（可直接粘贴）

给调色板库增加 CIEDE2000 色差度量，并保证批量性能与并发安全。约束：同色返回 0 且对称误差 ≤1e-12；与参考公式偏差不超过 1e-4；非有限输入与超范围亮度要给出可区分的错误类型；批量 10 万对耗时不超过 2 秒；并发调用不得共享可变状态；既有 Lab 转换结果逐位不变。验收：python -m pytest tests -q -k delta_e。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分，不在可见测试里）

- 非有限输入要报错
- 亮度为负要报错
- 远色对应大值
- 与参考实现偏差 ≤1e-4
- 不得新增依赖

## 运行方式

```bash
python -m pytest tests -q
```

初始 15 failed。可见测试只覆盖主功能（3 分线），通过不代表满分。
